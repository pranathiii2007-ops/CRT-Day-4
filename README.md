🔍 Python enumerate() Function

The enumerate() function allows us to access both the index and value of each element while iterating through a sequence.

numbers = [10, 20, 30, 40]

for index, value in enumerate(numbers):
    print(index, value)


Output:

0 10
1 20
2 30
3 40

⚡ Time and Space Complexity

Learned to compare different solutions and choose an efficient approach.

Time Complexity: Measures how the running time grows with the input size.
Space Complexity: Measures how the additional memory usage grows with the input size.

Common time complexities:

O(1) - Constant
O(log n) - Logarithmic
O(n) - Linear
O(n log n) - Linearithmic
O(n²) - Quadratic
👉 Two-Pointer Technique

The two-pointer technique uses two indices to process an array or string efficiently, often reducing the need for nested loops.

Common applications:

Moving zeros to the end of an array
Checking palindrome arrays
Solving pair-sum problems in sorted arrays
Sorting arrays containing limited distinct values
🏗️ Basics of Object-Oriented Programming (OOP)

Learned about the four main principles of OOP:

Encapsulation - Bundling data and methods together and controlling access to them.
Abstraction - Hiding implementation details and exposing essential functionality.
Inheritance - Creating classes that reuse or extend the functionality of other classes.
Polymorphism - Allowing a common interface to support different implementations.

Also explored the basics of classes, objects, methods, and function arguments.
